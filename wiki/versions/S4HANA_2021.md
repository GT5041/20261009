## 🆕 Universal Allocation の拡張

| 内容 | 詳細 |
|---|---|
| 原価センタ配賦 | **実績・計画の両方**に対応 |
| 利益センタ配賦 | 実績・計画の両方に対応 |
| 会社間配賦 | 実績: **FPS00**、計画: **FPS01**。同一管理領域内のみ、セグメントごとに送信会社コード 1 つ、会社内／会社間の混在不可 |
| Manage Cycle Run Groups | 依存関係のないサイクルを並行実行するためのアプリ |
| アプリ数 | FPS00 時点で 5 つの Fiori アプリ |
| FPS02 | 新機能なし |
| 制約 | 未決済明細管理勘定への転記不可 |
